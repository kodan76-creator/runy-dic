# Runy Dictionary (Рунный Словарь)

Интерактивный словарь рунного языка с панелью администратора и пользовательским интерфейсом.

## 📖 Описание

Проект представляет собой веб-приложение для работы со словарём рунного языка. Приложение включает:
- Пользовательский интерфейс для просмотра и поиска слов
- Панель администратора для управления словарём
- Систему аутентификации пользователей и администраторов
- 
## 🚀 Технологии

- **React 19** - библиотека для создания пользовательского интерфейса

- **ESLint** - линтинг кода

## 🔐 Шифрование и миграция

- **Ключ шифрования:** в CI/проде установите секрет `ENCRYPTION_KEY`. Без него приложение не сможет расшифровать JSON-файлы.
- **Миграция формата:** есть workflow `Migrate Encryption` (ручной запуск) — он создаёт ветку `migration/encryption-<timestamp>` и пушит изменения.
- **Резервные копии:** workflow теперь загружает `.bak` файлы как артефакт в run-artifacts — скачайте их перед мерджем на `main` для страховой копии.
- **Рекомендация:** не храните секреты в файловой системе репозитория. Поместите локальные переменные в `~/.env` и добавьте `.env` в `.gitignore`.

## 👥 Добавление администратора

1. Сгенерируйте хэш пароля в консоли браузера:

```javascript
// Загружаем библиотеку динамически
const script = document.createElement('script');
script.src = 'https://cdn.jsdelivr.net/npm/js-sha256@0.9.0/src/sha256.js';
document.head.appendChild(script);

// Подождите немного и затем выполните:
const hash = sha256("НОВЫЙ_ПАРОЛЬ");
console.log(hash);
```

2. Добавьте запись в файл `admins.json`:

```json
{
  "email": "new@admin.ru",
  "passwordHash": "скопированный_хэш",
  "createdAt": "2025-01-15T10:00:00.000Z",
  "role": "admin"
}
```

3. Закоммитьте и отправьте изменения:

```bash
git add admins.json
git commit -m "Add new admin"
git push origin main
```
