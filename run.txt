Как добавить нового админа:
1.Сгенерируйте хэш пароля в консоли браузера:
    // Загружаем библиотеку динамически
const script = document.createElement('script');
script.src = 'https://cdn.jsdelivr.net/npm/js-sha256@0.9.0/src/sha256.js';
document.head.appendChild(script);

// Подождите немного и затем выполните:
// const hash = sha256("НОВЫЙ_ПАРОЛЬ");
// console.log(hash);

2.Добавьте запись в admins.json:
    {
  "email": "new@admin.ru",
  "passwordHash": "скопированный_хэш",
  "createdAt": "2025-01-15T10:00:00.000Z",
  "role": "admin"
    }

3.Закоммитьте и отправьте:
    git add admins.json
    git commit -m "Add new admin"
    git push origin main
